# DaVinci Resolve Guide

A complete beginner-friendly DaVinci Resolve guide covering Free vs Studio, system requirements, Resolve pages, editing workflow, grading, captions, audio mixing, export settings, and learning resources.

## View the guide

Open `DaVinci Resolve Guide.html` directly in a browser.

## Topics covered

- Free vs Studio feature comparison
- Desktop and iPad requirements
- Media, Cut, Edit, Fusion, Color, Fairlight, Deliver, and Photo pages
- Short-form editing workflow
- Crushed-black and red-dominant grading
- Subtitles, watermark text, and Fairlight ducking
- 4K 60 fps export setup
- Official and free learning resources
